# Shripaad Koduri, Portfolio

My personal portfolio: the AI and automation systems I've built, the projects behind them, my skills and how to reach me.

Live: https://shripaad-portfolio17.vercel.app

## What's inside

- My story and what I work on
- Selected projects, each with a detail view and demo video
- Technical skills and the platforms I work with
- My resume, viewable on the page
- A contact section

## Built with

React 19, TypeScript, Vite, Tailwind CSS, GSAP, Motion and Lenis.

## Run it

```bash
npm install
npm run dev
```
